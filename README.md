# Gift Website

A small romantic static website to celebrate someone you love.

## How to use

1. Open `index.html` in a browser.
2. Replace the placeholder names and text with your own details.
3. Personalize the sections with your own memories, dates, and messages.

## Files

- `index.html` — main content
- `style.css` — styling and layout
- `script.js` — subtle sparkles animation

## Optional

You can also serve it locally with a simple web server:

```bash
cd gift-website
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
